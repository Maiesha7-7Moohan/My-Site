# My First Personal Portfolio Website

## Project Details
* **Developer Name:** Maiesha Moohan
* **Institution:** The Life Choices Academy (YouthCode Cohort 18)

## Short Project Description
This is a personal portfolio website designed to showcase my skills that I have learnt at the Life Choices Academy. The website contains 6 distinct internal layout views detailing my introduction, journey, design interests, future goals, and communication channels.

## Purpose of the Website
The primary purpose of this website is to serve as a beginner web development showcase piece for the Life Choices Academy. It acts as an showcase to my progression tech while visually reflecting my personal creative style, artistic voice, and long-term learning ambitions.

---

## Features of Your Project
* **Multi-Page Site Navigation:** A fully synchronized structural navigation bar that handles fluid routing across 6 layout elements (`index.html`, `about.html`, `goals.html`, `journey.html`, `interests.html`, `contact.html`).
* **Interactive Animated Hero Banner:** A vibrant landing hero showcase running a dynamic, looping 4-stop infinite linear-gradient background animation accompanied by a pulsing Call-to-Action (CTA) guide button.
* **Chronological Journey Matrix:** A clean, data table mapping out my education timeline, completed exercises, and weekly technical modules.
* **Creative Multi-Category Showcase:** An immersive visual gallery grouping my four primary creative dimensions (Fine Art, Jewelry Design, Coding, and Subculture Fashion) utilizing automated transform scales and smooth hover overlay cards.
* **Professional Communication Node:** Structured, high-contrast interactive layout blocks linked directly to my email address, active LinkedIn node, and primary GitHub repository.
* **Fluid Breakpoint Architecture:** A completely responsive framework that collapses and wraps complex multi-column layouts into stackable blocks for small touchscreens.

## HTML Concepts Used
* **Document Architecture:** Explicit declaration of `<!DOCTYPE html>`, along with standard structural `<html>`, `<head>`, and `<body>` tags.
* **Metadata Integrity:** Configured page-specific browser `<title>` attributes alongside critical `<meta charset="UTF-8">` and responsive mobile viewport rules.
* **Semantic Hierarchy:** Leveraged standard contextual elements (`<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`) to promote clean SEO crawlability and document accessibility.
* **Text Controls:** Organized textual contents using clearly divided heading hierarchies (`<h1>`, `<h2>`, `<h3>`, `<h4>`) and structured body blocks (`<p>`).
* **Asset Integration:** Linked internal and external endpoints via anchor elements (`<a>`) and mapped graphics using `<img />` sources equipped with contextual `alt` fallback text.
* **Structured Information Blocks:** Integrated unordered listings (`<ul>`, `<li>`) for navigation grids and goals, and implemented analytical matrices (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`) for layout tables.
* **UI Controls & Interactivity:** Built form-ready styling and active buttons (`<button>`) using inline window location triggers.
* **Code Maintenance:** Documented code sections using structured HTML comment blocks (``) alongside clean code indentation.

---

## CSS Concepts Used
* **Styles Linking:** Mapped all rules externally through a centralized layout sheet (`style.css`).
* **Selector Specificity:** Mixed element tags, modular classes (e.g., `.gallery-card`, `.nav-menu`), absolute identification markers, and universal canvas reset overrides (`*`).
* **Visual Styling:** Set a signature creative color palette utilizing soft pastel purples (`#c776d7`, `#805ac7`) and balanced golden interface highlights (`#e6d754`, `#e6cd45`).
* **Box Model Geometry:** Controlled padding, outer margins, borders, and width boundaries via global `box-sizing: border-box` calculations.
* **Advanced Positioning:** Formulated multi-layered element interfaces using fluid flow rules and absolute-to-relative coordinate overlays (`position: relative`, `position: absolute`).
* **Layout Layout Systems:** Built out completely from scratch using robust CSS Flexbox layouts and alignment parameters to align content structures neatly without third-party frameworks.
* **Hover & Micro-Interactions:** Triggered visual hover status alterations, anchor line underlines (`a::after`), scale amplifications (`transform: scale`), and progressive opacity filters (`opacity: 1`).
* **Custom Keyframe Animations:** Configured complex background loops (`gradientShift`), dropdown menus (`slideDown`), and warning actions (`pulse`) driven by custom `@keyframes` speeds and curves.
* **Media Adaptive Rules:** Implemented media queries (`@media (max-width: 768px)`) to transform multi-column tables and navigation menus cleanly into readable stack configurations.
